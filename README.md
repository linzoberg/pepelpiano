# Genshin Piano (desktop)

Десктопный клиент на **Python 3.10+ / PyQt5** для автоматического воспроизведения
последовательности клавиш (ноты виндхарпа/лиры: ряд 1 `QWERTYU`, ряд 2 `ASDFGHJ`)
в Genshin Impact. Собирается в один `.exe`-файл для Windows.

## Возможности

- Список ваших мелодий слева, добавление/редактирование/удаление прямо в интерфейсе.
- Хранение мелодий в `songs.json` рядом с программой — ничего не нужно редактировать руками.
- Единый интервал между нотами по умолчанию (изначально 500 мс) **или**
  индивидуальная задержка для каждой отдельной ноты (таблица в интерфейсе).
- Визуальная клавиатура — подсвечивается нажимаемая клавиша во время игры.
- Обратный отсчёт перед стартом (по умолчанию 3 сек), чтобы успеть переключиться в игру.
- Глобальная остановка клавишей **Esc** — работает, даже если фокус на окне игры.
- Импорт/экспорт мелодий в JSON — совместимо с веб-версией «Genshin Piano Studio».

## Требования

- Windows 10/11
- Python 3.10+
- Genshin Impact запущен в оконном или безрамочном оконном режиме
  (в полноэкранном режиме эмуляция клавиш может не доходить до игры)

## Установка и запуск в PyCharm

1. Откройте папку `desktop-app` как отдельный проект в PyCharm
   (File → Open… → выбрать `desktop-app`).
2. Создайте виртуальное окружение и установите зависимости:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Запустите `main.py` (Shift+F10) или через терминал:
   ```
   python main.py
   ```

## Добавление произведений

Прямо в приложении: кнопка **«+ Добавить»** → укажите название и
последовательность нот (только буквы `Q W E R T Y U A S D F G H J`, пробел — пауза)
→ «Сохранить». Мелодия тут же появится в списке и будет записана в `songs.json`.

Чтобы задать свой интервал для каждой ноты — поставьте галочку
«Индивидуальный интервал для каждой клавиши» и отредактируйте значения в таблице
(миллисекунды).

## Воспроизведение

1. Выберите мелодию в списке.
2. Нажмите **▶ Играть** — начнётся обратный отсчёт.
3. За это время переключитесь в окно Genshin Impact и встаньте у инструмента
   в режиме игры на нём.
4. Чтобы остановить в любой момент — кнопка **⏹ Стоп** или клавиша **Esc**
   (работает глобально).

## Сборка в .exe

```
pip install pyinstaller
python build_exe.py
```

Готовый файл появится в `dist/GenshinPiano.exe`, рядом будет скопирован `songs.json`
с вашими мелодиями. Эту папку `dist` можно переносить на любой Windows ПК —
Python устанавливать не нужно.

Вручную тем же PyInstaller:
```
pyinstaller --onefile --windowed --name GenshinPiano main.py
```

## Структура проекта

```
desktop-app/
├── main.py              # точка входа
├── core/
│   ├── storage.py        # модель Song + чтение/запись songs.json
│   └── player.py          # QThread, эмулирующий нажатия клавиш
├── ui/
│   ├── window.py          # главное окно
│   ├── dialogs.py         # диалог добавления/редактирования мелодии
│   └── styles.py           # тёмная золотая тема (QSS)
├── songs.json             # ваши мелодии (можно редактировать и вручную)
├── requirements.txt
└── build_exe.py            # автосборка .exe через PyInstaller
```

Архитектура разделена так же, как в `wifi-monitor`: `core/` — чистая логика без
PyQt, `ui/` — виджеты и стили, ничего не знающие о низкоуровневых деталях.

## Если клавиши не доходят до игры

- Запустите `GenshinPiano.exe` **от имени администратора**, если сама игра
  тоже запущена с правами администратора (иначе Windows не даёт одной
  программе слать события в другую с более высокими правами).
- Поставьте игру в оконный/безрамочный режим.
- Если `keyboard` всё равно не срабатывает в вашем случае, можно заменить
  вызов `keyboard.press_and_release` в `core/player.py` на библиотеку
  `pydirectinput` (`pip install pydirectinput`), которая эмулирует
  DirectInput и иногда лучше работает с играми на DirectX.

## Дисклеймер

Эмуляция нажатий клавиш — это автоматизация ввода. Используйте инструмент
аккуратно и на свой риск, ознакомившись с правилами использования стороннего
ПО в Genshin Impact. Проект не связан с HoYoverse и распространяется «как есть».
